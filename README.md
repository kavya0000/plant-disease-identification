# Plant Disease Identification System

## Overview
This project is an AI-based web application that detects plant diseases from leaf images using a CNN model.

## Features
- Upload plant leaf image
- Predict disease using deep learning model
- Displays result with disease name
- Suggests pesticide recommendations
- User login and registration system

## Tech Stack
- Frontend: HTML, CSS
- Backend: Django
- ML Model: CNN (TensorFlow/Keras)
- Database: SQLite / MySQL

## How to Run
1. Clone the repository
2. Install dependencies
3. Run: python manage.py runserver
4. Open: http://127.0.0.1:8000/
